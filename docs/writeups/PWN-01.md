# PWN-01 — Пульт управления (write-up для преподавателя)

**Рабочая программа по умолчанию:** `20003017fe`  
**Флаг по умолчанию:** `CTF{safe_vm_control}` (если администратор его не менял)

Это учебная задача на составление программы для ограниченной виртуальной машины, а не эксплуатация уязвимого native-кода. Формат ввода — hex-кодирование байтов программы.

1. Скачайте ELF `safevm` и изучите его таблицу инструкций. VM начинает со значением состояния `0x13`, обрабатывает короткую программу и принимает её, если инструкция `HALT` (`0xfe`) завершает программу точно в конце, исполнено не менее трёх инструкций, а состояние равно `0x2a`.
2. Для изменения состояния доступны операции `XOR` (`0x20`, за которым следует байт-операнд) и `ADD` (`0x30`, за которым следует байт-операнд). Инструкция `0xfe` — останов.
3. Соберите байткод:

   ```text
   20 00    XOR состояния с 0x00: 0x13 XOR 0x00 = 0x13
   30 17    прибавить 0x17:       0x13 + 0x17 = 0x2a
   fe       останов
   ```

   Здесь три инструкции: `XOR`, `ADD` и `HALT`. Введите их байты без пробелов в hex-поле: `20003017fe`.
4. После успешной проверки лаборатория покажет актуальный флаг. Начальное состояние, целевое состояние и операции можно проверить в предоставленном ELF.

Флаг по умолчанию может быть изменён администратором. VM принимает только ограниченный набор инструкций и не предоставляет доступа к памяти процесса, файловой системе, сети или командам ОС; это не классическая memory-corruption задача.
