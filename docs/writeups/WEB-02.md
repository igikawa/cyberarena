# WEB-02 — Посмотри исходник (write-up для преподавателя)

**Ответ:** `CTF{source_maps_are_not_needed}`

1. Откройте URL ресурса задания. Страница предлагает посмотреть исходный код и подключённые файлы.
2. В инструментах разработчика или через просмотр исходника найдите подключение `clue.js`.
3. Откройте `/static/tasks/web02/clue.js`. В локальном JavaScript найдите значение `pageNote` и отправьте его как флаг.

Здесь нет скрытого API, внешних CDN или сетевых зависимостей: HTML и JavaScript обслуживаются самой платформой как статические файлы.
