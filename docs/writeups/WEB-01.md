# WEB-01 — Скрытый документ (write-up для преподавателя)

**Ответ по умолчанию:** `CTF{idor_hidden_document}` (если администратор не менял флаг)

1. Откройте `/lab/`. Главная сообщает, что документ открывается по адресу `/documents/ID`.
2. Откройте публичную инструкцию ID `1001`; её содержимое упоминает документ руководителя `1002`.
3. Запросите `/lab/documents/1002`. Приложение возвращает синтетическую тестовую заметку с текущим флагом задания.

Причина: обработчик выбирает запись по идентификатору, но не проверяет, что текущему посетителю разрешено читать эту запись (IDOR / Broken Access Control). Лаборатория не имеет аутентификации, файловых или командных маршрутов и работает в отдельном контейнере только с двумя заранее заданными документами.
