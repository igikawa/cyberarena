# BIZ-01 — Магазин с ошибкой (write-up для преподавателя)

**Ответ по умолчанию:** `CTF{negative_quantity_credit}` (если флаг не меняли)

1. Откройте `/lab/shop/`. Баланс равен 100 кредитам, а премиальный пропуск стоит 250.
2. Форма принимает любое целое количество. Укажите `-1`: сервер считает итог как `250 * -1`, а проверка баланса сравнивает его с 100 без проверки положительности количества.
3. Заказ проходит ошибочную проверку и возвращает текущий флаг.

Баланс и заказ синтетические, состояние не сохраняется и сбрасывается на каждом запросе. Уязвимость существует только в лаборатории.
