# REV-01 — Машина состояний (write-up для преподавателя)

**Принимаемая строка по умолчанию:** `r3v_1s_fun!`  
**Флаг по умолчанию:** `CTF{reverse_the_machine}` (если администратор его не менял)

1. Скачайте ELF `revcheck` со страницы задания и исследуйте его локально, например, через `strings` и дизассемблер.
2. В функции `main` видно, что программа ожидает один аргумент заданной длины и сравнивает каждый его байт с соответствующим значением из массива `encoded`, предварительно применяя XOR с `0x5a`.
3. Восстановите строку, выполнив XOR каждого байта массива с `0x5a`:

   ```text
   28 69 2c 05 6b 29 05 3c 2f 34 7b
   XOR 5a для каждого байта
   72 33 76 5f 31 73 5f 66 75 6e 21
   ```

   ASCII-строка результата: `r3v_1s_fun!`.
4. Отправьте найденную строку через форму лаборатории. При успешной проверке лаборатория выдаёт актуальный флаг задания.

Бинарник не содержит флаг: он проверяет только ответ. Администратор может изменить флаг, поэтому указанный выше флаг — лишь значение по умолчанию. Задание предназначено для статического анализа локального файла; запускать неизвестные бинарники на рабочей системе не следует.
