# WEB-04 — За пределами папки (write-up для преподавателя)

**Ответ по умолчанию:** `CTF{virtual_paths_only}` (если флаг не меняли)

1. Откройте `/lab/files/` и прочитайте публичный `readme.txt`.
2. Просмотрщик нормализует путь, но не ограничивает его публичным каталогом. Передайте в поле пути `../../private/flag.txt`.
3. Виртуальный файл содержит текущий флаг задания.

Это намеренная ошибка обхода каталога только в словаре виртуальных файлов. Маршрут никогда не обращается к файловой системе контейнера.
