# WEB-03 — Архив сотрудников (write-up для преподавателя)

**Ответ по умолчанию:** `CTF{union_of_synthetic_records}` (если флаг не меняли)

1. Откройте `/lab/sql/` и выполните обычный поиск сотрудника, например `maria`.
2. Поле поиска небезопасно вставляется в SQL-запрос. Введите в него `' OR 1=1 --`, чтобы условие совпало со всеми строками.
3. В синтетической записи `auditor` появится текущий флаг.

Уязвимая база SQLite создаётся в памяти для каждого запроса и содержит только вымышленные записи. Она не связана с БД, файлами или данными платформы.
