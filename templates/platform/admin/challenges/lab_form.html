Платформа соберёт образ по Dockerfile, затем проверит /health напрямую и через Nginx. Сборка может скачивать базовые образы и обращаться в сеть. Не закрывайте страницу.

Проверки перед публикацией

  1. 1
    Безопасный архивПроверяются пути, типы и суммарный размер файлов.
  2. 2
    Ограниченная сборкаТолько локальная базовая платформа, без сети и секретов.
  3. 3
    Личный запускКонтейнер запускается под gVisor с лимитами ресурсов.
  4. 4
    Проверка через NginxПубликация только после успешного ответа приложения.
Приложение должно слушать 0.0.0.0:8000 и возвращать HTTP 200 по /health. Переменная LAB_CHALLENGE_FLAG передаётся только при запуске лаборатории. Разрешены пользовательские образы и Dockerfile для любых языков. 
# Python / FastAPI
FROM cyberarena/lab-base:custom
WORKDIR /srv/custom
COPY main.py .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
# PHP 7.4 (index.php должен обрабатывать /health)
FROM php:7.4.33-cli-alpine3.16
WORKDIR /srv/custom
COPY index.php .
CMD ["php", "-S", "0.0.0.0:8000", "index.php"]

Разрешены любые базовые образы, стадии сборки и инструкции Dockerfile, в том числе RUN и установка пакетов. Сборка выполняется в DinD под runc, а не под gVisor; загружайте Dockerfile только от доверенных администраторов. Секреты платформы в контекст сборки и переменные сборки не передаются. PHP 7.4 — устаревшая версия для учебных заданий.
